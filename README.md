# TechShop - Eletrónicos & Componentes 💻📱

Este é um projeto de um site de e-commerce focado na venda de telemóveis/celulares, peças eletrónicas, fontes de alimentação e processadores AMD Ryzen. O design do site foi construído seguindo uma identidade visual marcante e minimalista, utilizando **fundo preto (#000000)** e **texto amarelo (#FFFF2A)**.

O projeto foi reestruturado a partir de um sistema de flashcards interativos para se tornar numa loja funcional e responsiva.

---

## 🎨 Identidade Visual

- **Cor do Fundo:** `#000000` (Preto Absoluto)
- **Cor do Texto/Elementos:** `#FFFF2A` (Amarelo Vibrante)
- **Destaques:** Efeitos de hover interativos via CSS e JavaScript.

---

## 🚀 Funcionalidades

- **Navegação Rápida:** Menu funcional que ancora diretamente para as secções de Celulares, Peças ou Ryzen.
- **Estrutura em Cards:** Organização limpa dos produtos com imagens, títulos e preços estruturados.
- **Interatividade (JavaScript):** Ao passar o rato pelos cartões, a borda altera de cor e, ao clicar, o sistema simula a adição do produto ao carrinho de compras através de um alerta.

---

## 📂 Estrutura de Arquivos

O repositório deve conter os seguintes ficheiros:

1. `index.html` - Estrutura principal do site e das secções de produtos.
2. `style.css` - Estilização completa utilizando o padrão de cores pedido.
3. `script.js` - Lógica de interatividade (efeito hover e simulação de carrinho).
4. `LICENSE` - Licença MIT para utilização livre do código.
5. `README.md` - Documentação do projeto (este ficheiro).

---

## 🛠️ Como Executar o Projeto

1. Faça o clone ou descarregue os arquivos deste repositório.
2. Certifique-se de que todos os ficheiros (`index.html`, `style.css`, `script.js`) estão na **mesma pasta**.
3. Abra o ficheiro `index.html` em qualquer navegador web (Chrome, Edge, Firefox, Safari).
